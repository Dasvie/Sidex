# /qa [경로]

## 절차

1. `/dev` 로 서버를 띄운다. 경로가 없으면 `/`, `/c/engineering`, `/p/sidex`, `/p/linear`, `/submit`, `/u/sidex`, `/login` 순으로 돈다.
2. 화면마다 `screenshot` 과 `read_console_messages(onlyErrors:true)`. 폭 1280 과 390 두 번.
3. 아래 체크리스트를 캡처와 DOM(`read_page`)으로 판정한다. 로그인 필요한 흐름은 "사용자 확인 필요" 로 따로 적는다.

## 체크리스트

**문구**
- "—" 가 화면 어디에도 없다. 제목은 `X | Sidex`.
- 빈 상태 문구가 있다(빈 목록, 리뷰 없음, 논평 없음). 스켈레톤이 남아 있지 않다.
- 가상의 수치·이름이 없다. 소개 프로덕트의 빌드 노트에서 모르는 값은 "적히지 않음" / "측정 안 됨" 으로 보인다.

**디자인**
- Pretendard 가 적용됐다. CTA 는 그린 pill 하나뿐이다(`웹사이트 방문`, 등록 화면의 `등록`).
- 카드 라운드 16, 썸네일 12, 입력 8. 하이라인 1px `#e7e5e4`.
- 390px 에서 가로 스크롤이 없다. 랭킹 행의 숫자 박스가 잘리지 않는다.

**동작**
- 랭킹 순서가 `리뷰×3 + 논평×1 + 답글×0.5` 와 같다. 만든 사람 논평이 빠졌다.
- 제품 페이지: 웹사이트 방문이 새 탭으로 열린다. 링크 복사가 된다. 비슷한 프로덕트가 같은 카테고리에서만 나온다.
- 만든 사람은 자기 프로덕트에 리뷰를 못 쓴다(문구가 보인다).

**접근성**
- 포커스 링이 보인다. 별점 선택이 키보드로 된다. 이미지에 alt 가 있다(장식은 빈 alt).
